3D Сканер на iPhone

Установка без Mac — через шнур и ноутбук с Windows.

Скачать Scan3D-1.0.ipa

Статус сборки: build-status.txt

Один раз на ноутбуке

  1. Установите iTunes с сайта Apple (apple.com/itunes, версия для Windows — не из Microsoft Store). Нужен драйвер iPhone.
  2. Установите Sideloadly с сайта sideloadly.io.
  3. Скачайте файл Scan3D-1.0.ipa выше.

Установка

  1. Подключите iPhone шнуром, разблокируйте и нажмите «Доверять этому компьютеру».
  2. Откройте Sideloadly: iPhone появится в списке. Перетащите в окно файл .ipa.
  3. Введите Apple ID (лучше отдельный, не основной) и нажмите Start. Sideloadly подпишет приложение и установит его.
  4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
  5. iOS 16 и новее: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, перезагрузить.

Что умеет на разных iPhone

  • iPhone с лидаром (12 Pro, 13 Pro, 14 Pro, 15 Pro, 16 Pro, 17 Pro и Pro Max; iOS 16+): автоматический скан комнаты — стены, двери, окна и высота сами; скан предметов облаком точек; рулетка.
  • Остальные iPhone (XS / XR и новее): скан помещений по углам — отмечаете углы по полу, высоту, проёмы; рулетка. Скан предметов недоступен.

Важно

  • С бесплатным Apple ID приложение работает 7 дней, потом повторите «Установку» тем же файлом — сохранённые сканы останутся.
  • Готовый скан: кнопка «Отправить в «Замер и смета» / «Студию»» → «Сохранить в Файлы». В «Замер и смета»: ⚙ → «Восстановить копию» → выберите файл.
  • Копии всех выгрузок лежат в «Файлы» → «На iPhone» → «3D Сканер».
