ЗАМЕР И СМЕТА 2.5 ДЛЯ iPHONE — ПРОЕКТ XCODE

Внутри то же приложение, что на Android (папка ZamerSmeta/www), и «мост» для iPhone:
- данные хранятся в приложении; резервная копия — как на Android;
- Bluetooth-дальномеры: Bosch GLM/PLR, Leica DISTO и другие BLE-приборы (CoreBluetooth);
- приборы в режиме клавиатуры (HID) — через поле «Ввод с дальномера»;
- классический Bluetooth (SPP) iPhone не поддерживает — старые приборы без BLE не подключатся;
- выгрузки DXF, IFC, CSV, JSON, PDF: «Сохранить» кладёт файл в «Файлы → На iPhone → Замер и смета → Выгрузки», «Отправить» открывает меню «Поделиться».
- Входа по коду активации на iPhone нет — версия для личной установки.

КАК ПОЛУЧИТЬ .ipa БЕЗ MAC (через GitHub)
1. Создайте приватный репозиторий на GitHub и загрузите туда содержимое этой папки (вместе со скрытой папкой .github).
2. Вкладка Actions → «Сборка iOS» → Run workflow. Через 5–10 минут во вкладке появится файл ZamerSmeta-2.5-ipa.
3. Скачайте и распакуйте — получится ZamerSmeta-2.5-unsigned.ipa.

КАК УСТАНОВИТЬ НА iPHONE ЧЕРЕЗ ШНУР С НОУТБУКА WINDOWS
1. Установите iTunes (с сайта Apple, не из Microsoft Store) и Sideloadly (sideloadly.io).
2. Подключите iPhone шнуром, на телефоне нажмите «Доверять этому компьютеру».
3. В Sideloadly перетащите .ipa, введите свой Apple ID, нажмите Start.
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → Доверять.
5. iOS 16+: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, перезагрузить.
Ограничение бесплатного Apple ID: приложение работает 7 дней, потом повторить шаг 3 (данные сохраняются).
С платным аккаунтом разработчика Apple (99 $ в год) — на год и через TestFlight без шнура.

С MAC: brew install xcodegen; xcodegen generate; откройте ZamerSmeta.xcodeproj, выберите свою команду в Signing и запустите на телефоне.
