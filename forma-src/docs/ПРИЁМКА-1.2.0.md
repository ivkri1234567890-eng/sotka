# Форма 1.2.0 — доработка и приёмка (21.11.2026)

Не опубликовано: изменения собраны и проверены локально, на сайт и в GitHub не выкладывались.

## Причина пустого экрана /docs
`Docs.tsx` при открытии раздела «Чертежи» сразу вызывал `shot()` → `new FormaScene()` → `new THREE.WebGLRenderer()`.
Без WebGL конструктор бросал исключение во время отрисовки React, границы ошибок не было — дерево приложения размонтировалось,
на странице оставалась только кнопка хаба (её добавляет hub.js вне приложения).
Исправлено: `offscreen.ts` возвращает `null` вместо исключения, документы показывают 2D-проекции, PDF вставляет векторные проекции,
экраны обёрнуты в `Boundary`, каждый формат экспорта формируется отдельно, ZIP пишет ОШИБКИ.txt и продолжает.

## Эталон «Лагом» (tests/fixtures/lagom.forma.json — файл пользователя, JSON версии 1)
- S1: готовая 184 × 394, заготовка 183,6 × 392 — в редакторе, CSV, PDF, DXF обработки; все 19 деталей совпадают с CSV пользователя.
- Глубина по столешнице 420, максимальная с ручками 438 (420 − 10 вынос + 28 кнопка).
- R40: контур в DXF столешницы (ARC), путь со скруглением на виде сверху (сборочный чертёж, 2D-просмотр).
- Фасады F1/F2 выступают за скруглённые углы на 2,5 мм (x = 11 и 589 мм) — замечание и отметка на виде сверху.
- Ручка-кнопка: винт проходит фасад 16 + стенку ящика 16 = 32 мм → М4×40; отверстие Ø5 в стенке ящика, узел и порядок сборки в соединении.
- Смета: МДФ 16 под эмаль — одна группа листов; эмаль RAL 9016 и RAL 7004 — две операции; ЛДСП корпуса и коробов — один артикул.
