Замер и смета на iPhone

Установка без Mac — через шнур и ноутбук с Windows.

Скачать ZamerSmeta-2.5.ipa

Статус сборки: build-status.txt

Один раз на ноутбуке

  1. Установите iTunes с сайта Apple (apple.com/itunes, версия для Windows — не из Microsoft Store). Нужен драйвер iPhone.
  2. Установите Sideloadly с сайта sideloadly.io.
  3. Скачайте файл ZamerSmeta-2.5.ipa выше.

Установка

  1. Подключите iPhone шнуром, разблокируйте и нажмите «Доверять этому компьютеру».
  2. Откройте Sideloadly: iPhone появится в списке. Перетащите в окно файл .ipa.
  3. Введите Apple ID (лучше отдельный, не основной) и нажмите Start. Sideloadly подпишет приложение и установит его.
  4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
  5. iOS 16 и новее: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, перезагрузить.

Важно

  • С бесплатным Apple ID приложение работает 7 дней, потом повторите «Установку» тем же файлом — данные сохранятся. Sideloadly умеет продлевать автоматически, когда iPhone и ноутбук в одной Wi-Fi сети.
  • С платным аккаунтом разработчика Apple (99 $ в год) — на год, без повторов.
  • Дальномеры: Bosch, Leica и другие с Bluetooth Low Energy, а также режим клавиатуры. Старые приборы с классическим Bluetooth (SPP) iPhone не поддерживает.
  • Файлы выгрузок: «Файлы» → «На iPhone» → «Замер и смета» → «Выгрузки».

Без установки: веб-версия в браузере. На iPhone Safari не умеет Bluetooth — для дальномера откройте её в браузере Bluefy.
