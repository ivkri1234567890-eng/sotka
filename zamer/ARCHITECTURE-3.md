# Архитектура 3.0

Веб-приложение продолжает использовать формат проектов 2.9, ключ `zs:db` и хранилище IndexedDB `zamer-photos/ph`. Обычный замер создаётся прежней кнопкой. Дополнительные поля появляются при использовании новых функций.

## Инженерные коммуникации

`engineering.js` хранит карточки в `project.engineering`, видимость восьми категорий в `engineeringLayers`, состояние 3D в `engineering3d`. Единица хранения длин — метр, на карточке — миллиметр. Уклон хранится в процентах. Введённая пользователем точность и уровень отсчёта сохраняются отдельно. Условный размер значка в 3D служит для его видимости.

Карточка связана с ID помещения и постоянным ключом стены. После изменения длины координата отсчитывается от выбранного конца, в том числе вдоль дуги. После удаления стены или выхода отступа за её пределы элемент доступен через фильтр неопределённых привязок. Перетаскивание открывает числовую карточку для подтверждения. Внешняя зона с собственным именем, поверхностью и X/Y может задаваться от начала общего плана. Отображение домов в 3D и вывод общих листов доступны по этажам.

`eng-views.js` строит обозначения, привязки, ведомость, фотоальбом и элементы DXF и Three.js. 5D использует существующий график сметы. Регистрация точки инженерного замера сама по себе не начисляет цену и длительность работ. Bluetooth проходит по прежнему каналу измерений. В открытой карточке значение в метрах направляется в активное поле длины и переводится в миллиметры.

## Импорт чертежа

- `drawing-reader.js` читает ASCII DXF, PDF и растровые изображения. Для линий DXF учитываются слои, замыкание, вершины полилиний и поддерживаемые единицы. Для векторного PDF учитываются преобразования координат. На растровой подложке анализируются границы замкнутых светлых областей. Цифры по запросу распознаёт локальный Tesseract в отдельном рабочем потоке.
- `drawing-dialog.js` управляет выбором страницы, поворотом, увеличением, контрольными отрезками, вершинами, размерами стен и проёмами. Подпись рядом с линией или имя слоя могут дать предложение. Для проекта используются только подтверждённые помещения и проёмы.
- `drawing-project.js` проверяет масштаб, пересечения, конечные числовые значения и попадание проёмов в стены. Два масштаба с расхождением больше 2% блокируют подтверждение страницы. Длина и угол каждой стены вычисляются по вершинам. Исходное направление первой стены сохраняется в `drawingHeading`. Происхождение и контрольные размеры остаются в `drawingReview`.
- У каждой страницы собственная калибровка. Положение помещений на одной странице сохраняется относительно подложки. Высота комнаты вводится до создания. Дом получает этажи по подтверждённым назначениям, числовую отметку пола можно указать отдельно.

## Файлы, экспорт и офлайн

Оригиналы фотографий сохраняются отдельно от JPEG-превью. У инженерного фото один файл и список ID карточек. Копирование карточки добавляет ссылку. Удаление последней ссылки освобождает файл после успешной записи проекта. Фотография сохраняет также помещение и ключ стены на момент съёмки, если они известны.

Выбранный исходник чертежа хранится в той же IndexedDB с отдельным ID. При отказе браузера записать Blob приложение может сохранить исходные байты и MIME в той же записи, а при чтении восстановить Blob. При импорте ZIP бинарные данные получают новые ID. Веб-версия откатывает записи, если сохранение проекта не подтвердилось.

`media-zip.js` записывает проект, документы и медиа в один ZIP. SHA-256 и объявленный размер сверяются при восстановлении, для манифеста проверяется CRC. Указан предел архивов 256 МиБ. Исходный чертёж до 32 МиБ можно исключить из отдельного экспорта. PDF-альбом содержит планы, развёртки, ведомость и доступные фотопревью. Листы растеризуются для PDF последовательно, рабочий холст освобождается после каждого листа.

IFC2x3 передаёт пространства, обмеренные внутренние поверхности, известные размеры дверей и окон. Толщина и материал стены при таком замере неизвестны. Окно без высоты подоконника сохраняет размеры, его пространственное положение по высоте остаётся неопределённым. Соседние помещения имеют свои обмерные поверхности. Инженерные марки с назначением и точностью передаются в JSON, DXF и PDF.

`sw.js` устанавливает полный кеш до переключения версии. Он содержит также обработчик PDF и файлы распознавания цифр. Кеш относится к области регистрации приложения. Первое открытие требует сети. Проекты и фото остаются в хранилище устройства.

## Сторонние компоненты

Унаследованы локальные Three.js и JSZip. Добавлены Mozilla PDF.js 4.10.38 (legacy, основной модуль и worker собраны в IIFE через esbuild 0.25.12), Tesseract.js 6.0.1, tesseract.js-core 6.1.2 и компактная модель из @tesseract.js-data/eng 1.0.0. Для распознавания включены цифры, точка и запятая. Файлы лицензий и уведомления поставляются рядом с библиотеками. Приложение загружает эти компоненты с собственного адреса.
